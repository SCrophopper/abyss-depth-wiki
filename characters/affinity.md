# Character Affinity

This page preserves the rough relationship chart from the original lore journal.

| Symbol | Meaning |
|---|---|
| `>>>` | Trustworthy |
| `>>` | Close |
| `>` | Acquaintance |
| `<` | Conflict |

| Character | Relationship |
|---|---|
| Myke | `>>>` all members |
| Jonan | `>>>` all members; relationship with Myke shown as either `>>` or `<` |
| Selani | `>>>` all members except Myke and Jonan |
| Greg | `>>>` Myke; `>>` all members, including Rick |
| Rick | `>>>` Vlori; `>` all members except Cilia; `<` Cilia |
| Artie | `>>` all members except Cilia and Vlori; relationship with Vlori shown as either `>>>` or `<`; `>>>` Cilia |
| Vlori | `>>>` all members except Artie; relationship with Artie shown as either `>>>` or `<` |
| Cilia | `>` all members except Vlori, Artie, and Greg; `>>` Vlori, Artie, and Greg |

> The source intentionally presents some relationships as uncertain or variable.
