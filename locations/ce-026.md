# CE-026

**CE-026** is an underwater habitat in the European area. It provides a suitable location for the crew to establish their workshop and headquarters.

The location code describes both its region and construction order:

- **C** — Continent
- **E** — Europe
- **026** — the 26th building constructed in that area
